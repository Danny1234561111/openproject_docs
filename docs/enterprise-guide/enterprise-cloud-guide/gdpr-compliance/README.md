# GDPR
Общий регламент по защите данных (GDPR) — это европейский регламент, стандартизирующий правила в ЕС по обработке персональных данных частными компаниями или государственными организациями. GDPR также распространяет этот закон ЕС о защите данных на все иностранные компании, обрабатывающие данные резидентов ЕС. OpenProject естественным образом стремится к соответствию GDPR.

Как сторонник открытого исходного кода, OpenProject глубоко заинтересован в свободе пользователей. Это включает в себя свободы программного обеспечения, предоставляемые [GPLv3](https://www.gnu.org/licenses/quick-guide-gplv3.en.html) и используемые OpenProject, и, естественно, распространяется на права и свободы, предоставляемые Общим регламентом по защите данных (GDPR). В той же прозрачной манере, в которой мы разрабатываем наше программное обеспечение, мы стремимся к прозрачности и защите конфиденциальности данных наших пользователей.

## Информационная безопасность и соответствие требованиям

### Хостинговая инфраструктура
Облачная среда OpenProject размещена в логически изолированном виртуальном облаке Amazon Web Services, при этом все услуги расположены в Европе. AWS является [соответствующим GDPR](https://aws.amazon.com/compliance/gdpr-center/) поставщиком облачной инфраструктуры [с обширными программами безопасности и соответствия требованиям](https://aws.amazon.com/security/), а также непревзойденными механизмами контроля доступа для обеспечения конфиденциальности данных. Используемые объекты соответствуют стандартам ISO 27001 и 27018.

**Хостинг в ЕС**
Мы предлагаем безопасный хостинг вашего OpenProject cloud через Scaleway, при этом **все [субподрядчики](https://www.openproject.org/legal/data-processing-agreement/sub-processors/) базируются в Европейском Союзе**, обеспечивая полный суверенитет данных и соответствие нормам защиты данных ЕС.

Пожалуйста, [свяжитесь с нами](https://www.openproject.org/contact/) для получения дополнительной информации.

### Резервное копирование данных и https-шифрование
Облачная среда OpenProject непрерывно создает резервные копии данных с шифрованием данных при передаче (через TLS/https) и в состоянии покоя (файлы, база данных (включая резервные копии) через AES-256). Каждый отдельный экземпляр логически отделен, и данные сохраняются в уникальной схеме базы данных, что минимизирует риск перекрытия данных или утечки данных между экземплярами.

### Доступ к данным и инфраструктуре
Производственная инфраструктура доступна только ограниченному кругу авторизованного персонала по системным операциям через безопасный внутренний VPN для обслуживания. Сервисы, используемые сотрудниками, защищены двухфакторной аутентификацией, где это возможно. Доступ к данным клиентов осуществляется только по запросу клиента (т.е. в рамках запроса на поддержку или импорт/экспорт данных).

Все сотрудники OpenProject GmbH применяют стандартные меры безопасности данных для защиты своих устройств и доступа к облачной и локальной инфраструктуре. Все конфиденциальные пользовательские данные на ноутбуках и рабочих станциях зашифрованы, а машины поддерживаются для получения обновлений системы.

## Управление данными и портативность

GDPR предоставляет каждому субъекту данных право на доступ, изменение, получение и удаление своих собственных данных.

Клиенты OpenProject с учетными записями администратора в своем экземпляре действуют как контроллеры данных для своих членов команды и имеют комплексные инструменты для выполнения этих запросов от имени субъектов данных, за которых они несут ответственность.

Ниже мы кратко излагаем некоторые из этих ключевых прав на данные.

### Право на доступ и исправление
С помощью OpenProject контроллеры данных имеют детальное управление пользователями и правами для выполнения этих запросов. Отдельные субъекты данных могут направлять любые запросы своему назначенному контроллеру данных.

Следующие ресурсы предоставляют дополнительную информацию:
- [Управление учетными записями и пользователями в вашем экземпляре](../../../system-admin-guide/users-permissions/) (для контроллеров данных).

### Право на удаление («право на забвение»)
OpenProject предлагает способ полностью удалить всю идентифицируемую пользовательскую информацию из приложения. Если пользователь все еще упоминается в данных внутри экземпляра, эти ссылки заменяются анонимным пользователем для обеспечения целостности данных приложения.

- Контроллеры данных могут выполнить удаление [через административную панель](../../../system-admin-guide/users-permissions/users/).
- В зависимости от конфигурации вашего экземпляра OpenProject, отдельные субъекты данных могут выполнить удаление своей собственной учетной записи через страницу [Удаление учетной записи](../../../user-guide/account-settings/). Если эта возможность отключена, запрос может быть направлен контроллеру данных.

### Портативность данных
OpenProject позволяет контроллерам данных извлекать _все_ персональные данные, связанные с экземпляром OpenProject. Это включает все пользовательские и системные данные (в виде SQL-дампа), включая все загруженные файлы.

Теперь это возможно для контроллеров самостоятельно с использованием [функции резервного копирования OpenProject](../backups/).

## Подписание Соглашения об обработке данных (DPA) для Enterprise cloud

Согласно GDPR, клиентам из ЕС требуется подписать соглашение об обработке данных (иногда называемое дополнением об обработке данных), прежде чем использовать наше облачное издание Enterprise.

Начиная с OpenProject 11.1, мы автоматизировали этот процесс, чтобы сократить ручные усилия с обеих сторон. Таким образом, еще проще соблюдать GDPR.

Пожалуйста, перейдите в _Администрирование -> GDPR_, и теперь вы можете просмотреть и подписать ваш документ DPA непосредственно в приложении.

![DPA OpenProject в администрировании OpenProject](openproject_enterprise_guide_gdpr.png)

После подписания DPA вы можете **скачать** или **сбросить** его, нажав одну из соответствующих кнопок.

![Страница GDPR в администрировании OpenProject, показывающая кнопки для скачивания подписанного DPA и сброса DPA](openproject_enterprise_guide_gdpr_dpa_signed.png)

Узнайте больше о [функциях безопасности OpenProject](../../../security-and-privacy/statement-on-security/#openproject-security-features).

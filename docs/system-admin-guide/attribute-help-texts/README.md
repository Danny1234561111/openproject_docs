# Справки по атрибутам
<div class="glossary">
**Справки по атрибутам** предоставляют дополнительную информацию для атрибутов в рабочих пакетах и проектах. После их настройки они отображаются, когда пользователи нажимают на значок вопросительного знака рядом с пользовательскими полями в проектах и рабочих пакетах.
Таким образом вы уменьшите количество неправильных записей для атрибутов. Это особенно актуально для пользовательских полей, специфичных для компании.
</div>

Перейдите в _Администрирование_ -> _Справки по атрибутам_, чтобы настроить справки для атрибутов и пользовательских полей в рабочих пакетах и проектах. Здесь вы можете добавлять, редактировать и удалять справки по атрибутам.

## Добавление справок по атрибутам
Чтобы добавить справку по атрибуту для пользовательских полей, нажмите на зеленую кнопку **+ Справка по атрибуту**.
1. **Выберите атрибут**, который вы хотите пояснить, из выпадающего меню. Этот список включает атрибуты рабочих пакетов и пользовательские поля.
2. Добавьте **заголовок** для предоставления дополнительного контекста.
3. Добавьте **текст справки**. Вы также можете добавить встроенные изображения, ссылки или видео. Эта справка будет показана пользователям в формах рабочих пакетов или проектов.
4. Добавьте **вложения**, например выдержки из руководства по процессам.
5. **Сохраните** изменения.
![Добавление новой справки по атрибуту в администрировании OpenProject](openproject_system_admin_guide_attribute_help_texts_add.png)
> [!ПРИМЕЧАНИЕ]
> Обратите внимание, что текст справки будет виден во всех проектах.
После того как вы настроили справку для атрибута, участники проекта могут видеть пояснение. Они увидят значок вопросительного знака рядом с атрибутом.
Когда пользователи нажимают на него, они видят описание для этого атрибута.
![Пример описания справки по атрибуту](openproject_system_admin_guide_attribute_help_texts_example.png)
## Редактирование или удаление справок по атрибутам
Перейдите в _Администрирование_ -> _Рабочие пакеты_ -> _Справки по атрибутам_, чтобы отредактировать или удалить справку по атрибуту.
1. Нажмите на **название** атрибута, чтобы отредактировать существующую справку по атрибуту. Альтернативно вы также можете редактировать справку по атрибуту при просмотре её в рабочем пакете.
2. Нажмите на **значок удаления**, чтобы удалить справку по атрибуту.
![Редактирование или удаление справок по атрибутам в администрировании OpenProject](openproject_system_admin_guide_attribute_help_texts_edit_delete.png)
## Рабочие пакеты
Справки по атрибутам для рабочих пакетов отображаются в [детальном представлении](../../user-guide/work-packages/work-package-views/#split-screen-view) (как на скриншоте ниже) и в [полноэкранном представлении](../../user-guide/work-packages/work-package-views/#full-screen-view). Они помогут пользователям (например, менеджерам проектов) понять, какую информацию вносить в какие поля.
![Пример справки по атрибуту в представлении рабочего пакета в OpenProject](openproject_system_admin_guide_attribute_help_texts_example_wp.png)
## Проекты
Справки по атрибутам для проектов отображаются на [Домашней странице проекта](../../user-guide/projects/project-home/) (как на первом скриншоте ниже) и в [Настройках проекта](../../user-guide/projects/project-settings/project-information/) (как на втором скриншоте ниже).
Они помогут пользователям (например, менеджерам проектов) понять, какую информацию вносить в какие поля.
![Справки по атрибутам на странице обзора проекта](openproject_system_admin_guide_attribute_help_texts_project_overview_page.png)
![Справки по атрибутам на странице информации о проекте](openproject_system_admin_guide_attribute_help_texts_project_settings_page.png)
## WYSIWYG редактор
Справки по атрибутам также могут отображаться в WYSIWYG текстовом редакторе с использованием определенного синтаксиса. Узнайте больше [здесь](../../user-guide/wysiwyg/#embedding-of-work-package-attributes-and-project-attributes).

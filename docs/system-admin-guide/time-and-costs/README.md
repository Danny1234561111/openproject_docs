# Время и затраты
Перейдите в _Администрирование_ -> _Время и затраты_, чтобы настроить глобальные параметры для отслеживания времени и затрат в OpenProject. Вы можете определить настройки и ограничения для записи времени, настроить параметры затрат, управлять типами затрат и видами деятельности отслеживания времени, а также настроить валюту, используемую для отчетов о затратах.
## Параметры времени и затрат по умолчанию
Чтобы определить глобальные настройки для записи времени и затрат, перейдите в _Администрирование_ -> _Время и затраты_ -> _Значения по умолчанию и ограничения_.
Выберите вкладку _Время_, чтобы настроить запись времени, или вкладку _Затраты_, чтобы настроить параметры затрат.
### Определение параметров времени по умолчанию (дополнение Enterprise)
[feature: time_entry_time_restrictions ]
На вкладке _Время_ администраторы могут настроить, как пользователи записывают время, и определить глобальные ограничения для записей времени. Эти настройки применяются ко всем проектам.
По умолчанию ограничения записей времени отключены, сохраняя существующее поведение без ограничений.
#### Время начала и окончания
Раздел **Время начала и окончания** контролирует, могут ли записи времени включать конкретное время начала и окончания.
- **Разрешить время начала и окончания**: Позволяет пользователям вводить время начала и окончания при записи времени. Если отключено, пользователи могут вводить только количество затраченного времени. Когда эта опция включена, представление календаря по умолчанию отображается на странице _Мое отслеживание времени_. Когда она отключена, по умолчанию отображается представление списка.
- **Требовать время начала и окончания**: Делает время начала и окончания обязательными при записи времени.
#### Ограничения
Раздел **Ограничения** определяет глобальные ограничения для записей времени. Эти ограничения проверяются при создании или изменении записи времени и применяются ко всем проектам.
- **Максимальное количество часов на одну запись времени**: Ограничивает количество часов, которые можно записать в одной записи времени. Введите `0` для отсутствия ограничений.
- **Максимальное количество часов в день**: Ограничивает общее количество часов, которые пользователь может записать за один день по всем записям времени. Введите `0` для отсутствия ограничений.
- **Не разрешать запись времени в нерабочие дни**: Запрещает пользователям записывать время в дни, определенные как нерабочие. Это включает глобальные нерабочие дни, настроенные администратором, а также личные нерабочие дни, возникающие из-за индивидуальных настроек рабочего времени пользователя.
- **Ограничение рабочими часами пользователя**: Ограничивает общее количество часов, которые пользователь может записать за день, его эффективными рабочими часами на этот день. Пользователи без определенного рабочего времени не ограничены этой настройкой.
- **Не разрешать запись за прошедшие месяцы**: Запрещает пользователям добавлять, изменять или удалять записи времени, относящиеся к месяцу, который уже закончился. При включении записи времени обычно можно изменять только за текущий месяц.
- **Льготный период для прошедших месяцев**: Определяет количество дней в начале нового месяца, в течение которых пользователи еще могут добавлять, изменять или удалять записи времени за предыдущий месяц. Например, значение `5` позволяет пользователям изменять записи времени за предыдущий месяц до пятого дня текущего месяца. Введите `0` для отсутствия льготного периода.
Нажмите **Обновить ограничения**, чтобы сохранить изменения.
![Параметры по умолчанию для записи времени в администрировании OpenProject](openproject_system_admin_guide_time_time_defaults.png)
### Определение параметров затрат по умолчанию
1. Настройте **валюту, используемую в системе**, например EUR.
2. **Укажите формат валюты**, включая то, должен ли символ или код валюты появляться до или после суммы, например `100 EUR` или `$100`.
3. Нажмите **Сохранить**, чтобы сохранить изменения.
![Настройки времени и затрат в администрировании OpenProject](openproject_system_admin_guide_time_costs_defaults.png)
## Создание и управление типами затрат
Вы можете создавать и управлять **типами затрат**, чтобы [относить удельные затраты к рабочим пакетам в OpenProject](../../user-guide/time-and-costs/cost-tracking/).
Перейдите в _Администрирование_ -> _Время и затраты_ -> _Типы затрат_, чтобы создавать и управлять типами затрат.
### Создание типа затрат
Нажмите зеленую кнопку **+ Тип затрат**, чтобы создать новый тип затрат.
Вы можете настроить следующие параметры:
1. Введите **название** для типа затрат.
2. Определите **название единицы** для этого типа затрат, например Евро, штука, день и т.д.
3. Установите **название единицы во множественном числе**, например Евро, штуки, дни и т.д.
4. Определите **текущую ставку**.
5. Выберите, должен ли тип затрат быть **типом затрат по умолчанию** при учете новых удельных затрат.
6. Выберите, должен ли тип затрат быть **активирован для всех проектов**. Эта опция выбрана по умолчанию.
Нажмите **Сохранить**, чтобы создать тип затрат.
![Создание нового типа затрат в администрировании OpenProject](openproject_system_admin_guide_time_costs_new_cost_type.png)
### Управление типами затрат
Обзор типов затрат отображает существующие типы затрат. Вы можете отфильтровать список, чтобы показать активные или заблокированные типы затрат.
Чтобы заблокировать тип затрат, нажмите **значок блокировки** в правом конце соответствующей строки.
> [!СОВЕТ]
> Вы можете **блокировать, но не удалять** типы затрат.
![Обзор типов затрат в администрировании OpenProject](openproject_system_admin_guide_time_costs_cost_types_overview.png)
### Редактирование типа затрат
Нажмите на название типа затрат, чтобы отредактировать его.
Настройки типа затрат разделены на три вкладки:
#### Детали
Вкладка **Детали** содержит те же настройки, что и при создании типа затрат. Здесь вы можете изменить его название, названия единиц, текущую ставку, статус по умолчанию и активацию проекта.
![Вкладка Детали для редактирования типа затрат в администрировании OpenProject](openproject_system_admin_guide_time_costs_cost_type_details_tab.png)
#### История ставок
Вкладка **История ставок** позволяет определить различные ставки для типа затрат и указать, когда каждая ставка становится действительной.
![Вкладка История ставок для управления ставками типов затрат и датами их действия в администрировании OpenProject](openproject_system_admin_guide_time_costs_cost_type_rate_tab.png)
Чтобы добавить новую ставку, нажмите **+ значок**. Затем:
1. Установите **дату**, с которой новая ставка должна быть действительна.
2. Введите **ставку** в указанной единице.
3. Нажмите **Сохранить**, чтобы применить изменения.
Чтобы удалить ставку, нажмите **значок удаления** рядом с ней.
#### Проекты
Вкладка **Проекты** показывает проекты, в которых тип затрат включен.
![Вкладка Проекты, показывающая проекты, в которых тип затрат включен](openproject_system_admin_guide_time_costs_cost_type_projects_tab.png)
Если на вкладке **Детали** выбрано **Для всех проектов**, тип затрат включен во всех проектах.
Чтобы сделать тип затрат доступным только в определенных проектах, снимите флажок **Для всех проектов** на вкладке **Детали** и выберите соответствующие проекты здесь.
> [!ПРИМЕЧАНИЕ]
> Типы затрат также могут использоваться для учета других видов единиц в рабочих пакетах, таких как дни отпуска, отгулы или командировочные дни. Например, вы можете использовать `1` в качестве единицы для отслеживания дней отпуска по бюджету отпусков и оценивать их в [отчетах о затратах](../../user-guide/time-and-costs/reporting/).
## Создание и управление видами деятельности отслеживания времени
Чтобы получить обзор существующих видов деятельности отслеживания времени, перейдите в _Администрирование_ -> _Время и затраты_ -> _Виды деятельности отслеживания времени_. Вы можете управлять элементами в списке, используя параметры в меню **Еще (три точки)** с правой стороны. Вы также можете изменить их порядок, используя маркер перетаскивания слева.
![Обзор существующих видов деятельности отслеживания времени в администрировании OpenProject](openproject_system_admin_guide_time_costs_time_tracking_activities_overview.png)
> [!ПРИМЕЧАНИЕ]
> Чтобы активировать [Виды деятельности для отслеживания времени](../../user-guide/projects/project-settings/time-and-costs) в определенном проекте, перейдите в _Настройки проекта -> Время и затраты_.
### Создание нового вида деятельности отслеживания времени
Чтобы создать новый вид деятельности отслеживания времени, нажмите кнопку **+ Добавить** в правом верхнем углу.
Введите название для вида деятельности и выберите, должен ли он быть активным. Нажмите **Сохранить**, чтобы создать вид деятельности.
![Создание нового вида деятельности отслеживания времени в OpenProject](openproject_system_admin_guide_time_costs_time_tracking_activities_new.png)
### Редактирование или удаление вида деятельности отслеживания времени
Чтобы **отредактировать** существующий вид деятельности отслеживания времени, либо нажмите его название, либо выберите **Редактировать** в меню **Еще (три точки)** в правом конце строки.
![Редактирование вида деятельности отслеживания времени в администрировании OpenProject](openproject_system_admin_guide_time_costs_time_tracking_activities_edit_icon.png)
Чтобы удалить вид деятельности отслеживания времени, откройте меню **Еще (три точки)** в правом конце строки и нажмите на **значок удаления**.

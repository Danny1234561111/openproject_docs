# Руководство пользователя

Добро пожаловать в Руководство пользователя OpenProject.

Это руководство охватывает все функциональные возможности OpenProject с точки зрения пользователя.

## Обзор проектов в OpenProject

Ваша работа в OpenProject может быть организована в несколько проектов, каждый из которых имеет отдельный набор участников и их соответствующие роли в этом проекте. В свою очередь, каждый проект может быть индивидуально настроен в отношении включенных функций, называемых _Модулями_ в OpenProject. Это различие между проектами предоставляет вам большую гибкость в организации вашей работы и контроле того, что пользователям разрешено просматривать и/или над чем сотрудничать в каждом отдельном проекте.

Как Community edition, так и Enterprise edition позволяют создавать неограниченное количество проектов для разделения вашей работы. Чтобы узнать больше о создании и управлении проектами в OpenProject, [посетите наш отдельный раздел о проектах](projects/).

## Обзор модулей в OpenProject

<div class="glossary">
**Модуль** определяется как независимая единица функциональности, которую можно использовать для расширения и улучшения существующих основных функций.
</div>

Внутри проекта модули могут быть активированы и деактивированы в разделе "Модули" в меню настроек проекта участниками проекта, у которых есть достаточные разрешения для изменения настроек проекта. Какие модули или отдельные функции будут доступны в проектах, контролируется в глобальных настройках Администрирования (пожалуйста, ознакомьтесь с [Руководством системного администратора](../system-admin-guide/projects), чтобы узнать, как это делается).

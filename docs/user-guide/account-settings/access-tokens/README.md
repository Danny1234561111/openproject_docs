# Токены доступа
Чтобы просматривать и управлять вашими токенами доступа OpenProject, перейдите в **Настройки аккаунта** и выберите **Токены доступа** из меню. Токены доступа позволяют вам предоставлять внешним приложениям доступ к ресурсам в OpenProject.
![Обзор токенов доступа в настройках аккаунта OpenProject](openproject_account_settings_access_tokens.png)
Токены доступа организованы в две вкладки: Токены провайдера и Токены клиента. Токены провайдера генерируются OpenProject и позволяют другим приложениям подключаться к нему. Токены клиента генерируются внешними приложениями и позволяют OpenProject подключаться к ним.
## Токены провайдера
Токены провайдера создаются в OpenProject и позволяют внешним приложениям получать доступ к OpenProject. Они включают API, iCalendar, iCalendar для совещаний, OAuth и RSS токены.
### API
API токены позволяют сторонним приложениям общаться с этим экземпляром OpenProject через REST API. Если API токены еще не созданы, этот список будет пуст. Вы можете включить REST веб-сервис API и CORS в [_Администрирование -> API и вебхуки_](../../../system-admin-guide/api-and-webhooks/).
![Токены доступа в настройках аккаунта OpenProject](openproject_account_settings_access_tokens_api.png)
Чтобы создать новый API токен, нажмите **+ API токен**, назовите токен в открывшейся форме и нажмите кнопку _Создать_.
![Назвать и создать новый API токен в OpenProject](openproject_account_settings_access_tokens_api_create_new.png)
Будет сгенерирован новый API токен и отображен. Пожалуйста, имейте в виду, что каждый токен отображается только один раз при его создании, поэтому важно скопировать и безопасно сохранить его. Если вы потеряете эту информацию, вы МОЖЕТЕ удалить старые токены и сгенерировать новые.
> [!TIP]
> Мы рекомендуем использовать каждый токен только для одной цели (например, для одного приложения), чтобы вы точно знали, что нужно заменить, если вам потребуется удалить его.
![Сообщение, подтверждающее успешную генерацию нового API хранилища в OpenProject](openproject_account_settings_access_tokens_api_generated.png)
### iCalendar
iCalendar токены позволяют пользователям подписываться на календари OpenProject и просматривать актуальную информацию о рабочих пакетах из внешних клиентов.
Этот список будет пуст, если у вас еще нет подписок на календари.
![Список календарей OpenProject в настройках аккаунта, показывающий, что на календари еще не подписаны](openproject_account_settings_access_tokens_calendar_list.png)
После того как вы [подпишетесь на календарь](../../calendar/#подписаться-на-календарь), здесь появится список всех календарей, на которые вы подписаны. Название календаря кликабельно и приведет вас непосредственно к соответствующему календарю в OpenProject.
![Список календарей OpenProject в настройках аккаунта, показывающий токены календаря](openproject_account_settings_access_tokens_calendar_list_with_content.png)
Вы можете удалить запись в списке iCalendar, нажав на значок **Удалить**. Это вызовет предупреждающее сообщение с просьбой подтвердить решение об удалении. Удалив этот токен, вы больше не будете иметь доступ к информации OpenProject во всех связанных клиентах, использующих этот токен.
![Удалить календарь OpenProject в настройках аккаунта](openproject_account_settings_access_tokens_delete_calendar.png)
Затем вы увидите сообщение о том, что токен и URL iCal теперь недействительны.
![Токен доступа к календарю OpenProject недействителен](openproject_account_settings_access_tokens_calendar_invalid.png)
### iCalendar для совещаний
Токены iCalendar для совещаний позволяют пользователям подписываться на все свои совещания и просматривать актуальную информацию о совещаниях во внешних клиентах.
Этот список будет пуст, если у вас еще нет подписок на календари. Как только вы подпишетесь на календарь совещаний, здесь появится список всех токенов iCalendar для совещаний.
Чтобы подписаться, нажмите кнопку **Подписаться на календарь** непосредственно в ваших настройках аккаунта или в [модуле совещаний](../../meetings/#подписаться-на-совещания).
![Кнопка "Подписаться на календарь" для подписки на совещания OpenProject в настройках аккаунта](openproject_account_settings_access_tokens_subscribe_button.png)
Затем вы можете назвать токен подписки на совещания и нажать **Создать подписку**.
![Форма для создания нового токена подписки iCal для совещаний в настройках аккаунта OpenProject](openproject_account_settings_access_tokens_subscribe_meetings_form.png)
Затем вы увидите вновь сгенерированный токен.
> [!IMPORTANT]
> Это единственный раз, когда он будет отображен. Убедитесь, что вы скопировали его и безопасно сохранили.
![Вновь сгенерированный токен подписки на совещания iCal в настройках аккаунта OpenProject](openproject_account_settings_access_tokens_subscribe_meetings_form_confirmation.png)
Чтобы удалить токен iCal для совещаний в Настройках аккаунта, нажмите значок _Удалить_ рядом с соответствующим названием токена.
![Значок удаления для удаления токена iCal для совещаний в настройках аккаунта OpenProject](openproject_account_settings_access_tokens_meetings_delete.png)
### OAuth
Токены OAuth позволяют сторонним приложениям подключаться к этому экземпляру OpenProject, например Nextcloud (см. [здесь](../../file-management/nextcloud-integration/) как настроить интеграцию с Nextcloud). Приложения OAuth можно создавать в [_Администрирование-> Аутентификация_](../../../system-admin-guide/authentication/).
Токены OAuth не создаются непосредственно в OpenProject. Вместо этого процесс авторизации запускается из внешнего приложения. Во время настройки вы будете перенаправлены в OpenProject для подтверждения доступа, а затем возвращены во внешнее приложение для завершения подключения.
Если интеграция со сторонним приложением еще не активирована, этот список будет пуст. Пожалуйста, свяжитесь с вашим администратором, чтобы помочь вам настроить ее.
Как только интеграции существуют, их токены появятся здесь. Вы можете отозвать доступ в любое время, выбрав значок **Удалить**. Удаление токена немедленно удаляет разрешение внешнего приложения действовать от вашего имени, что означает, что оно больше не может выполнять вызовы API от вашего имени. Если вы хотите снова использовать интеграцию, вам нужно будет снова авторизовать ее.
![Токены OAuth OpenProject в Моем аккаунте](openproject_account_settings_access_tokens_oauth.png)
### RSS
Токены RSS позволяют пользователям быть в курсе последних изменений в этом экземпляре OpenProject через внешний RSS-ридер. Вы можете иметь только один активный RSS токен.
Создайте новый токен, нажав кнопку **RSS токен**.
![RSS токен в OpenProject в настройках аккаунта](openproject_account_settings_access_tokens_rss.png)
Это создаст ваш токен и вызовет сообщение, показывающее вам токен доступа.
> [!IMPORTANT]
> Вы сможете увидеть токен доступа RSS только один раз, непосредственно после его создания. Убедитесь, что скопировали его.
![Новый RSS токен создан в OpenProject](openproject_account_settings_access_tokens_rss_new.png)
После создания RSS токена вы увидите детали здесь и сможете удалить его, нажав значок **Удалить**.
![Значок удаления RSS токена в настройках аккаунта OpenProject](openproject_account_settings_access_tokens_rss_delete.png)
## Токены клиента
Токены клиента генерируются внешними приложениями и позволяют OpenProject подключаться к ним.
### OAuth
Токены клиента OAuth позволяют этому экземпляру OpenProject подключаться к внешним приложениям.
Если вы еще не связали свой аккаунт с какими-либо интеграциями, активированными для вашего экземпляра, этот список будет пуст. Вы можете удалить токены, нажав значок **Удалить**.
![Токены доступа к файловым хранилищам в Настройках аккаунта в OpenProject](openproject_account_settings_access_tokens_file_storages.png)
